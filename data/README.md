# 데이터 입력

원본 리뷰 데이터는 저장소에 포함하지 않습니다. 교육 과정에서 제공받은 `data.csv`를 이 폴더에 놓거나 `DATA_PATH` 환경 변수로 경로를 지정하세요.

| 열 | 의미 |
|---|---|
| text | 리뷰 문장 |
| aspect | 리뷰에서 언급한 속성 |
| label | 해당 속성의 감성: 부정 0, 긍정 1 |

`example.csv`는 구조 설명용으로 새로 작성한 합성 예문입니다. 학습 성과를 낸 원본 데이터가 아닙니다. 속성 존재 검출에서는 감성 0도 언급된 속성이므로 존재 라벨 1로 변환합니다.
