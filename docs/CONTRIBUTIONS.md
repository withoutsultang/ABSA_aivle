# 수행 범위

## 김건우 개인 실습

- 리뷰 text별 속성을 중복 제거해 모으고 MultiLabelBinarizer로 11차원 multi-hot 구성
- BERT 다중 레이블 분류 입력과 float32 라벨 구성
- DataCollatorWithPadding과 float 라벨 collator 적용
- 일반 파인튜닝·LoRA 학습 및 속성별 precision/recall/F1/support 평가·시각화

개인 실습 수행은 본인이 확인했습니다. 교육 과정에서 제공한 과제와 골격을 바탕으로 진행한 실습이며, 저장소는 그 수행 결과를 포트폴리오로 정리한 것입니다.

## 팀 프로젝트

리뷰 감성 → 속성 검출 → 속성별 감성의 세 단계 실습을 notebooks/team에 보관했습니다. 팀의 문서상 검토 역할은 형식상 분담이므로 개인 QA 성과로 기재하지 않았습니다.
